# KIET-TRIAL-WEB-SITE
# KIET University Website 🌐

## 📌 About the Project
This is my **first-ever web development project**, created using HTML, CSS, and JavaScript. It is a student-created website concept inspired by KIET University.

The project helped me practice the fundamentals of web development and learn how to structure and design a website.

## 🔗 Live Demo
Visit the website here:  
https://2630btech1078-wq.github.io/KIET-TRIAL-WEB-SITE/

## ✨ Features
- 🏠 Home section with a welcome message
- 🎓 About KIET section
- 📚 Academic courses and programs
- 📝 Admissions information
- 📞 Contact information
- 🧭 Navigation menu for easy browsing
- 🎨 Custom styling and page layout

## 🛠️ Technologies Used
- **HTML5** – Structures the webpage
- **CSS3** – Styles the website and layout
- **JavaScript** – Adds basic interactivity

## 🚀 How to Run the Project
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the website.
